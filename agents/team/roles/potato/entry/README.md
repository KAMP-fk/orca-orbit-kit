# Potato｜レビュー受付

Banana が開発を終えた案件を受け、実装に未関与の担当が確認します。
ここはレビューの入口です。実際のレビューは案件ごとの独立したワークツリーで行います。

1. Banana が開発成果と確認対象のコミットをそろえる。
2. その固定 SHA から、開発とは別のレビュー用ワークツリーを作る。
3. Potato が受入条件、差分、CI、必要な検証を確認する。
4. 指摘や質問を Banana に返し、修正後の成果を確認する。

レビューのモデルは **Opus 5.5 / high 固定**です。別モデルへ自動で切り替えません。
技術・受入レビューに同じ指定を使い、最終独立レビューは実装・修正に未関与の別タスクへ引き渡します。
署名 verdict は対象プロジェクトの権限と正式な手順に従います。
実装担当の自己 PASS を禁止し、対象プロジェクトの CI・署名・人間ゲートに従います。

依頼は Banana に渡してください。案件からレビューを進める入口は `banana review`、
Potato の種別と手順を表示するコマンドは `potato --inbox` です。
この表示窓口ではモデルを自動起動しません。
